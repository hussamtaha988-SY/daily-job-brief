# فرص العمل اليومية · Daily Job Brief

أداة مجانية ترسل لك كل صباح **05:00 بتوقيت دبي** ملف HTML + PDF فيه فرص العمل
المناسبة لسيرتك الذاتية: الخليج حضوري/هجين + وظائف عن بُعد من أي مكان.

مبنية على نفس بنية نشرة الأخبار: GitHub Actions + Gmail SMTP + Python.
**لا تحتاج مفتاح ذكاء اصطناعي** — الفلترة والمطابقة تعمل بقواعد ثابتة، بلا حصة ولا تكلفة.

---

## ما تفعله الأداة

1. تجمع إعلانات الوظائف من مصادر مجانية.
2. تفلترها على بروفايلك المرشح (خبرة متوسطة 3–7 سنوات، عربي/إنجليزي).
3. ترتّبها بنسبة مطابقة، وتعرض حتى 20 فرصة.
4. ترسلها إلى بريدك مع ملف PDF مرفق.

### المصادر

| المصدر | يغطي | الحالة |
|---|---|---|
| LinkedIn — البحث العام | الخليج حضوري/هجين + عن بُعد | الأساسي |
| Remotive | عن بُعد عالميًا | يعمل |
| RemoteOK | عن بُعد عالميًا | يعمل |
| Himalayas | عن بُعد عالميًا | يعمل |
| Jobicy | عن بُعد عالميًا | يعمل |
| Arbeitnow | أوروبا + عن بُعد | يعمل |
| WeWorkRemotely | عن بُعد عالميًا | يعمل |

> Bayt وGulfTalent وIndeed وNaukrigulf يحجبون الوصول الآلي (HTTP 403)، لذلك
> غير مضمّنين. LinkedIn هو المصدر الوحيد الذي يغطي وظائف الخليج الحضورية.

### ما أُعيد استخدامه من منصتك القديمة (GulfCareer_Local)

| الجزء المنقول | الفائدة |
|---|---|
| واجهة تفاصيل الوظيفة في LinkedIn | تقرأ **المستوى الوظيفي الحقيقي** (Entry / Mid-Senior / Director) والوصف الكامل، بدل التخمين من العنوان |
| سجل التقديمات (22 طلبًا) | الوظائف التي قدّمت عليها سابقًا **لا تظهر مرة أخرى** — `data/applied_ids.json` |
| فكرة «المعرّفات المرئية» | سجل `data/seen_ids.json` يمنع تكرار نفس الوظيفة يومًا بعد يوم؛ يحفظه GitHub تلقائيًا بعد كل إرسال |
| لوحات الشركات المباشرة | Tamara و Careem و Deliveroo (Greenhouse) و **Aldar** (Lever) — 98 وظيفة خليجية، بلا مفاتيح وبلا حجب |
| مولّد روابط البحث | Bayt و GulfTalent و Naukrigulf و Dubizzle و LinkedIn Easy Apply ومنشورات التوظيف — روابط جاهزة في آخر النشرة |

لم يُنقل: واجهة FastAPI والـ BAT (الأداة الجديدة تعمل بلا جهازك)، و Michael Page (صار يعطي 404)، وخطابات التغطية بالذكاء الاصطناعي (تحتاج مفتاحًا مدفوعًا).

> **خصوصية:** ملفا `applied_ids.json` و `seen_ids.json` يحتويان **أرقام إعلانات وظائف عامة فقط** — لا اسم ولا بريد ولا هاتف. إن لم ترغب بنشر أرقام تقديماتك، احذف محتوى `applied_ids.json` واتركه `[]`.

### الفلاتر الصارمة (تُستبعد ولا تُخفّض فقط)

- **أقدم من النافذة الزمنية**: الخليج 48 ساعة، عن بُعد 7 أيام.
- **وظائف المواطنين فقط**: `UAE National`, `Emirati`, `GCC National`… إلخ.
- **فوق المستوى أو تحته**: `Senior`, `Lead`, `Director`, `Head`, `Intern`, `Trainee`…
- **لغة عمل لا تتقنها**: أي وظيفة يذكر عنوانها لغة غير العربية/الإنجليزية
  (95 لغة مستبعدة)، بالإضافة إلى وظائف `Linguist`/`Transcriptionist` التي
  لا تذكر العربية أو الإنجليزية.
- **خارج المجال**: أي عنوان لا يطابق عائلات الوظائف الأربع.
- **عن بُعد مقيّد جغرافيًا**: وظائف Remote تقبل مرشحين من أمريكا/كندا/أوروبا فقط.

### عائلات الوظائف المستهدفة

1. **إدارة ومساندة تنفيذية** — Administrative Officer, Office Administrator,
   Executive Assistant, Personal Assistant, Office Manager…
2. **قانوني ومستندات وعقود** — Legal Assistant, Paralegal, Legal Secretary,
   Contracts Administrator, Document Controller, Company Secretary,
   Business Setup, PRO, Compliance…
3. **ترجمة وتحرير ولغات** — Translator, Interpreter, Proofreader, Editor,
   Localization, Content Writer, Copywriter, Quality Control…
4. **تنسيق ومتابعة عملاء** — Client Coordinator, Operations Coordinator,
   Project Coordinator, Client Relations…

## التركيب على GitHub (خطوة بخطوة)

### 1. أنشئ مستودعًا جديدًا

من **GitHub Desktop**: `File` ← `New Repository`

- Name: `daily-job-brief`
- Local Path: اختر مجلدًا تعرفه
- **مهم**: اترك `Private` **غير مؤشّر** — Actions مجاني بلا حدود على المستودعات العامة.
- اضغط `Create Repository`

> مستودع منفصل عن مستودع نشرة الأخبار، حتى لا تتأثر النشرة الشغالة.

### 2. انسخ ملفات الأداة

- فك ضغط الحزمة.
- في GitHub Desktop اضغط `Repository` ← `Show in Explorer`.
- انسخ **محتويات** المجلد المفكوك (وليس المجلد نفسه) والصقها في مجلد المستودع.
- تأكد أن `.github` موجود — في Windows قد يكون مخفيًا، فعّل إظهار الملفات المخفية.

### 3. Commit و Publish

- في GitHub Desktop اكتب رسالة مثل `Daily job brief` ← `Commit to main`
- اضغط `Publish repository` ← تأكد أن `Keep this code private` **غير مؤشّر** ← `Publish`

### 4. أضف المفاتيح (نفس مفاتيح نشرة الأخبار)

افتح في المتصفح:

```
https://github.com/<اسمك>/daily-job-brief/settings/secrets/actions
```

أضف **ثلاثة** أسرار فقط — `New repository secret`:

| Name | Value |
|---|---|
| `GMAIL_USER` | نفس بريد Gmail المرسل الذي تستخدمه في نشرة الأخبار |
| `GMAIL_APP_PASSWORD` | نفس كلمة مرور التطبيقات (16 حرفًا) |
| `DIGEST_TO` | البريد الذي يستقبل النشرة (بريدك) |

> لا تحتاج `GEMINI_API_KEY` هنا — الأداة لا تستخدم ذكاءً اصطناعيًا.
> لا تكتب أي بيانات شخصية في `config.yaml` لأن المستودع عام.

### 5. شغّل التجربة الأولى

- تبويب `Actions` ← `Daily Job Brief` ← `Run workflow`
- أول مرة اختر `dry_run = true` للتأكد أنه يعمل بلا إرسال.
- ثم شغّله مرة أخرى بـ `dry_run = false` ليصلك البريد فعليًا.

بعدها يعمل تلقائيًا كل يوم **05:00 بتوقيت دبي**.

## الضبط

كل الإعدادات في `config.yaml`:

```yaml
settings:
  hours_window: 48            # نافذة الخليج
  remote_hours_window: 168    # نافذة عن بُعد (7 أيام)
  max_items: 20               # إجمالي الفرص
  max_gulf: 12
  max_remote: 8
  max_per_company: 2          # لا تسيطر جهة واحدة على النشرة
  min_score: 30               # حد المطابقة الأدنى
  linkedin_pause: 2.5         # تهدئة الطلبات لتجنب الحجب
```

لتغيير المسميات المستهدفة، عدّل `profile.families` — أضف أو احذف مسميات.
لتغيير الدول، عدّل `gulf_locations`.

## التشغيل محليًا (اختياري)

```bash
pip install -r requirements.txt
python src/main.py --dry-run            # يبني الملفات في out/ بلا إرسال
python src/main.py --gulf-only          # تجربة أسرع: الخليج فقط
python src/main.py --remote-only        # عن بُعد فقط
python src/main.py --max-items 5        # عدد أقل للتجربة
```

للإرسال الفعلي محليًا: انسخ `.env.example` إلى `.env` واملأ القيم.
**لا ترفع `.env` إلى GitHub أبدًا** (مُدرج في `.gitignore`).

### فلاتر أُضيفت بهذه النسخة
- **already-applied** — قدّمت عليها سابقًا.
- **already-sent** — وصلتك في نشرة سابقة.
- **seniority:verified** — LinkedIn نفسه يصنّفها Director / Executive / Internship.
- **language-desc** — شرط لغة صريح داخل الوصف مثل «native French speaker».
- إعلانات الشركات تُقبل خلال **14 يومًا** (لأنها تبقى مفتوحة أسابيع)، مع منع التكرار.

## حدود صريحة

- **LinkedIn غير رسمي**: واجهة البحث العامة قد تتغير أو تفرض قيودًا (HTTP 429).
  الأداة تهدّئ الطلبات وتعيد المحاولة، ولو فشل المصدر تكمل النشرة بالمصادر
  الأخرى ويظهر تنبيه بالمصدر الناقص.
- **الوظائف عن بُعد الإدارية/الترجمة قليلة عالميًا**: معظم لوحات العمل عن بُعد
  تقنية. لذلك عدد فرص «عن بُعد» أقل من الخليج في العادة، وهذا ليس خللًا.
- **نسبة المطابقة** تقيس قرب الإعلان من سيرتك، وليست احتمال قبولك.
- **الأداة لا تقدّم نيابة عنك** ولا ترسل سيرتك لأي جهة. التقديم دائمًا عبر
  الموقع الأصلي للمعلن.
- **05:00 هدف وليس ضمانًا**: GitHub قد يتأخر دقائق على المواعيد المجدولة.
- قد يمر إعلان مكرر أو منتهي؛ الرابط الأصلي هو المرجع النهائي.

### ملاحظة عن واجهة التفاصيل
واجهة LinkedIn غير رسمية. إذا ردّت بـ HTTP 429 تتوقف الإثراء تلقائيًا وتكمل النشرة بالمعلومات الأساسية — لا يفشل التشغيل. في تجربتنا المحلية نجحت الإثراء لوظيفتين فقط بسبب كثرة الاختبارات على نفس العنوان؛ على GitHub يكون العنوان جديدًا فتعمل بشكل أفضل.

## رموز الخروج

- `0` نجاح، أو تجربة `--dry-run`
- `2` فشل إرسال البريد (المفاتيح أو SMTP)
- `1` خطأ غير متوقع
